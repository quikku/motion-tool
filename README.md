# SisMotionTooL

ブラウザでHumanoidのモーションを作り、UnityのAnimationClip（.anim）として保存するツールです。

https://quikku.github.io/motion-tool/

この公開ページは茜犬だけの見本です。骨を回してキーを打ち、「.anim保存」を押すと、Unityで使える.animができます。ほかのアバターへの対応は想定していません。

作ったモーションは、ブラウザの中で処理するだけで、外部には送信しません。

「プロジェクト保存」で、キーや呼吸の設定をそのまま.sismotionファイルに残せます（.animは呼吸を焼き込むので、開き直しても元のキーには戻りません）。.sismotionは、骨の名前が違うアバターで開いても、人型の骨（腰・背骨・腕・脚・指など）はそのまま動きます。元のポーズが大きく違う（TポーズとAポーズなど）と腕の角度がずれますが、Unityから開いたアバターどうしならUnityの人型と同じ基準で合わせます。

## IK

「IK」が入っていると、手先・足先・頭・腰に水色の四角が出ます。四角を動かすと、腕・脚、頭なら背骨と首が付いてきます。桃色の四角は頭の向きの的で、動かすと首と頭がそちらを向きます。

- 腰の四角を動かすと、足先はその場に残って膝が曲がります（足を固定していなくても）。回すと腰だけが回り、背骨が逆に回って胸の向きを保ちます（上限に当たった分は胸も回ります）。足も一緒に動かしたいときは、腰の四角をしまって腰の骨を動かすか、ルート（緑の四角）を動かします。
- ツールバーの「▾」で、IKごとに出す・しまうを決められます。最初に出ているのは手と足だけで、頭・視線・腰はここから出します。しまったIKの所は、ふつうの骨として回せます。
- 「▾」でIKを固定すると、そのIKは体を動かしてもその場に残ります（赤い四角）。ツールバーの「固定」を切ると、固定がまとめて効かなくなります。IKごとの固定は覚えているので、入れ直せば元どおりです。たとえば足を固定して腰を下げる、頭を固定して上半身をひねる、視線を固定して体の向きを変える、ができます。最初は手と足が固定されています。
- 出す・固定の設定は、ブラウザに覚えておきます。

## 手パッド

手首か指の骨を選ぶと、3D表示の右上に手の絵が出ます。指の骨を一つずつ回さなくても、絵をドラッグして指を動かせます。

- 赤い所を縦にドラッグすると、その関節が曲がります。Shiftを押しながらだと、その指の関節を全部まとめて曲げます。
- 手のひら（真ん中の赤い線）を縦にドラッグすると、親指以外の4本をまとめて曲げます（グー・パー）。
- 青い所を横にドラッグすると、指が開く・閉じます。
- 赤・青の所をクリックすると、その骨を選びます。
- 「対称」が入っていると、反対の手も同じだけ動きます。「上限」が入っていると、曲げすぎないようにします。

絵は手の甲から見た形です。上の帯（左手・右手のボタンの横）をドラッグすると、置く場所を変えられます。ツールバーの「手パッド」で出さないようにできます。

## 相手役（2人目のアバター）

2人で組むモーションは、2体を並べて作れます。実験的な機能なので、「設定」の下の「実験的な機能」で「使う」にすると出ます。

1. ツールバーの「相手 ▾」を押し、「同じアバター」か「フォルダから…」「ファイルから…」で2体目を出します（FBXと画像。あれば`.motiontool.json`も）。最初は今のアバターの正面に、向かい合わせで立ちます。
2. 「位置」と「向き」で置き場所を決めます。重なるところが見にくいときは「半透明」にします。ツールバーの「相手を表示」で、相手役を隠したり出したりできます。
3. キーを打てるのは、動かしているほうの1体です。「⇄ 1体目」（Q）を押すと、動かすほうが入れ替わります。相手役は最初「ロック」されていて、クリックしても触れません。ロックを外すと、相手の体のクリックでも入れ替わります。もう1体は、自分のキーのとおりに一緒に再生します（fpsが違っても時刻でそろえます）。
4. 手を相手の肩に置くようなところは「くっつける」を使います（ロックを外しておきます）。IKで手先か足先（または腰）を選び、今のフレームで置きたい所に合わせてから「選んだ手足・腰 → 相手の体…」を押し、相手の体をクリックします。範囲と間隔を決めて「キーを打つ」と、相手が動いても付いたままになるように、その範囲にキーを打ちます。腕や脚が届かないフレームがあれば知らせます。相手の動きを変えたら、もう一度打ち直します。「視線 → 相手の顔」で、首と頭を相手の顔に向けたキーも同じように打てます。タイムラインの「全体」の行には、相手役のキーの時刻が細い線で出ます。
5. .animは1体ずつ保存します（動かしているほうが保存されます）。Unityでは、ポップアップの「Unityでは:」に出る置き方で2体を置くと、ここで見たとおりに組み合います。

ほかに、相手役の.sismotionを開く、今の動きを相手役に写す、もできます。2体の置き場所と動きは、.sismotionにまとめて残ります。「ファイルから」出した相手役は、開き直したあとに同じモデルをもう一度選ぶと戻ります。

Unityから開いたときは、シーンの別のアバターも相手役にできます。Unityでそのアバターを選んで`Tools/SisMotionTooL`を押すと、別のタブで開きます。そのタブを開いたまま、元のタブで「相手 ▾」の「Unityの別のタブ…」から選びます。衣装なども、そのアバターのとおりに出ます。.animを保存すると、それぞれのアバターでUnityが書きます。

「フォルダから…」「ファイルから…」で出した違うアバターは、Unityから開いたページでは.animを保存できません（Unityは、開いたアバターと骨が合わない.animは書きません）。.sismotionに保存して、そのアバターで開き直してください。

## 動きの補正

これも実験的な機能です。「実験的な機能」を「使う」にすると、ツールバーに「補正」が出ます。呼吸と同じく、キーは変えずに、再生と保存のときだけ上に足します。

- 足のすべり止め: 床に着いている足が滑らないようにして、床に沈んだ足は床まで上げます。その場で歩く・走るループは、床がベルトのように流れているとみなします
- 重心を足の上に: 重心が足の範囲から出たら、腰を寄せます。動いているときは勢いの分も見込みます
- 空中は放物線: 両足とも浮いている間、体の上下を重力どおりにします
- 遅れ: 胸・頭・腕が少し遅れて付いてきます。強さは%で変えます

床には、着いている足（緑の輪）、足の範囲（緑の線）、重心（白い点。外に出ると赤）が出ます。前に倒れて走るような、わざと重心を外した動きには「重心を足の上に」は合いません。人型でないモデルでは効きません。

## 自分のアバターで使う

Unityのスクリプトを使うと、シーンのアバターをこのツールで開けます。

1. [MotionTool.unitypackage](MotionTool.unitypackage)をUnityにインポートします（Unity 2022.3で確認。アバターはHumanoidです。人型でないモデルは下の「人型でないモデル」）。
2. ヒエラルキーでアバターを選び、`Tools/SisMotionTooL`を押します。ブラウザでそのアバターが開きます。
3. 骨を回してキーを打ち、「.anim保存」を押します。Assetsの中に.animができます。

既にある.animは、右クリックして`SisMotionTooL/開く`で開けます。

改変したアバターは、シーンで見えているままの姿で開きます。シェイプキーや骨の大きさで変えた体型と、着せた衣装・髪・アクセも出ます。衣装の揺れものは揺れずに、付いている骨と一緒に動きます。作業の邪魔になる物は、「表示」タブか右クリックで隠せます。隠した物はアバターごとに覚えます。

## 人型でないモデル

動物やロボットなど、UnityでHumanoidにしていない（Genericの）モデルも開けます。ヒエラルキーでそのモデルを選んで`Tools/SisMotionTooL`を押すと、骨を回してキーを打てます。

- 位置を動かせるのは、ルート（緑の四角）と、そのすぐ下の骨（骨の付いたメッシュのいちばん上の骨）だけです。ほかの骨は回すだけです。
- IK・手パッド・呼吸・上限は、人型の骨を使うので使えません。「対称」と「ポーズ ▾」の反転は、骨の名前の左右（L / R、Left / Right）で効きます。
- .animは、骨ごとの回転のカーブになります（ルートか、そのすぐ下の骨にキーがあるときは、その骨の位置も）。シェイプキーは人型のときと同じです。
- 骨の付いたメッシュ（SkinnedMeshRenderer）の無いモデルは開けません。
- 選んだ物にAnimatorが付いていれば、そのモデルを開きます。.animの骨のパスは、そのモデルから数えます。Animatorが無くても、骨の付いたメッシュ（SkinnedMeshRenderer）があれば開けます（モデルの根か、中の骨かメッシュを選びます）。
