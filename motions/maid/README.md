# 無邪気なメイドのモーション集

会話の合間に入れる、ちょっとした動き61本と、姿勢と姿勢の間をつなぐ動き18本です（立って28本、椅子13本、床16本、寝て4本、つなぎ18本）。SisMotionTooLの`.sismotion`で入っています。

## 使い方

1. SisMotionTooLを開き、「開く」で`.sismotion`を選びます（画面にドラッグしても開けます）。
2. 「.anim保存」を押すと、UnityのAnimationClipができます。

人型の骨（腰・背骨・腕・脚・指）は、骨の名前が違うアバターで開いても動きます。手と手を合わせる動き（拍手・ハート・合掌など）は、体の大きさや腕の長さが茜犬と違うと、少し離れたり重なったりします。そのときは開いたあとに手の位置を直してください。

## つなぎ方

- 繰り返しの待機（`Maid_Idle`など）以外は1回だけ再生する動きで、どれも「手を前で重ねて立つ」姿で始まり、同じ姿で終わります。待機から出て待機に戻るように並べると、動きがつながります。
- 椅子の動き（`Sit_`）は、どれも「ひざの上で手を重ねて座る」姿（`Sit_Idle`）で始まって終わります。
- 床の動きは、同じ座り方どうしでつながります。正座（`Floor_Seiza_`）は「ももの上に手を置いた正座」、ぺたん座り（`Floor_Petan_`）は「ひざの間の床に手をついた姿」で始まって終わります。
- 立つ・座る・寝るの間は、つなぎの動き（`Trans_`）でつなげます。つなぎの最初と最後は、その姿の基本の形です。1回だけの動きと寝ている動きは、この形で始まります。待機の動き（`Maid_Idle`・`Sit_Idle`・体育座りなど）は基本の形のまわりで少し揺れているので、Animatorでは短く（0.1〜0.2秒ほど）重ねて切り替えてください。

## 表情

表情（シェイプキー）は付けていません。体の動きだけです。

## 座る動き

- 椅子は、茜犬の体で座面が床から約39cmの高さです（ももが水平、すねが垂直、足の裏が床）。腰の高さは.animに入っているので（Root Transform Position (Y) を Bake Into Pose、Based Upon: Original）、ワールドでは座面の高さに合わせてアバターの置き場所（Stationなど）を決めてください。体の大きさが違うアバターでは、座面の高さもその体に合わせて変わります。
- 床は、正座・ぺたん座り・体育座り・足を伸ばして座る、の4つの座り方です。お尻（正座は足の甲も）が床に着く高さにしています。

## 寝る動き

- 仰向け・横向き・うつ伏せで寝る3本と、うつ伏せでほおづえをついて足をぱたぱたする1本です。どれも繰り返しで、ゆっくり息をする動きだけが入っています。
- 表情を付けていないので、寝ている動きでも目は開いたままです。目を閉じるのは、アバターやワールドの表情の仕組みでしてください。
- 体は床に寝た高さです。どれも、立っていたときの後ろの方へ頭を向けて寝ます（仰向けから右へ転がると横向き、さらに転がるとうつ伏せ）。寝返りのつなぎで、そのまま転がれます。
- お尻の位置は、体育座り・足を伸ばして座る・寝る、でそろえています。

## つなぎの動き

つながる姿は次のとおりです（どれも両方向あります）。

- 立つ ↔ 椅子に座る
- 立つ ↔ 正座
- 正座 ↔ ぺたん座り
- 立つ ↔ 体育座り
- 体育座り ↔ 足を伸ばして座る
- 足を伸ばして座る ↔ 仰向け
- 仰向け ↔ 横向き ↔ うつ伏せ（寝返り）
- うつ伏せで寝る ↔ うつ伏せでほおづえ

正座やぺたん座りから寝るときは、立つ → 体育座り → 足を伸ばす → 仰向け、のように順につなぎます。
